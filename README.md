# Student Performance Predictor

## Overview
A Machine Learning project that predicts whether a student is likely to Pass or Fail based on academic performance data.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Model
- Decision Tree Classifier

## Dataset
UCI Student Performance Dataset

## Features Used
- Age
- Study Time
- Failures
- Absences
- G1 Grade
- G2 Grade

## Results
- Accuracy: 86%
- Pass/Fail Prediction

## Future Improvements
- Random Forest
- XGBoost
- Streamlit Web Application
